Dome actions in the graph

  • New Dome lane under Overall: Open (blue), Closed (grey), Opening/Closing (lavender) for the minutes the dome is moving.
  • Action markers: ▲ open, ▼ close, each with its trigger in the tooltip: Manual, ASCOM, Schedule, Safety auto-close, Safety auto-open, Rain auto-close.
  • Dashed lines through all lanes at each action, so cause and effect (e.g. Rain turns red, then Rain auto-close) read at a glance.
  • Hover gets a "Dome" row with state at that minute.
  • Hidden when the Dome feature is disabled, same as other lanes. Dome state isn't an input to Overall.
  • Data note: dome state and actions are recorded from the day this ships (hooked into open/close requests); earlier hours show no Dome data.
  • Current status: the blank space left of the red Now line shows each lane's live value as a colored pill (SAFE, Open, Night, Dry, Clear...), so the chart doubles as a status panel.
  • AI lanes match the others: AI Sky Pred. and AI Cloud Detect are two block lanes (Clear / Cloudy / Overcast, same colors as MLX/ML Cloud) instead of a line chart. Cloud Detect uses the family map (partly/mostly cloudy → Cloudy; overcast, rain, snow, freezing rain → Overcast).
